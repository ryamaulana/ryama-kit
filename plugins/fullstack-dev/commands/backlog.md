Dari pemilik: $ARGUMENTS

Delegasikan ke agent `backlog` (mode sesuai isi: tanpa argumen dan belum ada `docs/backlog.json` = susun awal; ada argumen = masukan baru; "apa berikutnya" = usulan batch). Beri catatan saja, bukan riwayat chat. Ikuti skill `project-context`. Setelah selesai tampilkan laporannya apa adanya (progres, batch berikutnya, keputusan yang menunggu pemilik) dan sebut `docs/BACKLOG.md` untuk daftar lengkap.
