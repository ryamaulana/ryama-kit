# Indeks komponen tampilan (`web/src/ui/`)
Satu baris per komponen. Gaya: `web/src/ui/styles/index.css` (tokens.css impor `docs/design-tokens.css` + font Overpass lokal, base.css), diimpor sekali di `web/src/main.tsx`. Tema: `data-theme="light|dark"` di `<html>` (tanpa atribut = ikut sistem). Pratinjau: `/app/preview.html?layar=kerangka|daftar|baru|proyek&tema=terang|gelap&keadaan=…` (daftar: kosong, memuat, galat, diam; proyek: jeda, henti, stop, enam; baru: isi, folder, folder-memuat, folder-kosong, folder-galat, folder-baru, folder-hilang, akar, sibuk, penuh, kosong-teks, model, mengirim).
