# Kendali run lewat program `claude` asli, bukan Agent SDK

Crew Control menjalankan program `claude` asli dalam mode tanpa layar (stream-json), bertindak sebagai tuan rumah izin lewat stdio, dan memakai hook HTTP untuk Jeda dan sesi desktop. Paket Agent SDK ditolak walau API-nya lebih rapi, karena dokumen Anthropic meminta API key untuk produk berbasis SDK, sedangkan pemilik memakai login langganan; program asli dengan langganan sendiri untuk pemakaian sendiri diizinkan (bukti: `docs/SPIKE.md`, A1). Akibatnya dashboard bergantung pada format stream-json dan hook yang bisa berubah antar versi Claude Code; parser dikurung di `src/harness/stream.ts` dan dites dengan `claude` tiruan. Syarat yang tidak boleh dilanggar: tidak membaca, menyimpan, atau meneruskan token login, dan tidak memakai `--bare`.
