# Referensi desain dari pemilik (2026-10-27)

Berkas di folder ini adalah referensi visual dari pemilik. Baca gambarnya langsung, jangan hanya mengandalkan catatan ini.

- `orchestrateiq-live-agent-map.png`: OrchestrateIQ, Live Agent Map. Terang, ruang lega, panel dan kartu lembut, status berupa pill kecil, peta agent di tengah dengan detail node di panel kanan.
- `orchestrateiq-workflow-node.png`: OrchestrateIQ, kanvas workflow. Kartu node berisi jawaban/ringkasan, pill status, token, dan waktu; konektor tipis; rel ikon di kiri.
- `oreflow.png`: Oreflow. Kartu node dengan tab warna di atasnya, angka besar sebagai pusat perhatian, konektor tebal, kanvas bertitik.

## Yang pemilik mau (kata pemilik)
- Gabungan OrchestrateIQ dengan node ala n8n: workflow terlihat live seperti kanvas, dan detail tetap terlihat. Bentuk penempatan detail (tab, sidebar, sidebar setengah tersembunyi) diputuskan UX agent.
- Clean dan terstruktur. Isi versi sekarang tetap, hanya lebih jelas.
- Kartu node berisi data nyata, bukan ikon saja.
- Tema terang dan gelap.

## Yang pemilik tidak suka
- Tampilan generik seperti AI slop.
- Mockup "arah A Gading" (docs/mockups/arah-a): terasa tidak clean dan tidak sesuai referensi. Layar penuh (tiga kartu indikator, kotak Butuh input besar, grafik terhimpit, panel kanan, rel) dan arah visual tidak mengikuti referensi di atas.
